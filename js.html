TIPSKeamanan & Penanganan Error Global

Tanpa penanganan error global yang baik, satu payload data yang tidak valid atau request API yang gagal (misal: mencoba mengirim pesan ke pengguna yang telah memblokir bot) dapat menyebabkan seluruh proses Node.js Anda terhenti (crash).
